# LotWatch downloads

Built copies of LotWatch for Windows and macOS. There is no source code here.

## Install

**Windows.** Download `LotWatch-<version>-windows-x64.zip` from the [latest release](../../releases/latest), unzip it anywhere and run `LotWatch.exe`. Windows may ask for confirmation the first time, because the app is not signed with a paid certificate.

**macOS 14 or later.** Download `LotWatch-<version>-macos.zip` from the [latest release](../../releases/latest), unzip it and move LotWatch to the Applications folder. The first launch needs Control-click, Open, because the build is not notarized.

## Updates

An installed copy checks this page a few times a day and offers new versions in its own window. Every release is signed, and a copy installs only what carries that signature.

The other files in a release (`latest.json`, `latest.json.sig`, `LotWatch-<version>.asar`) are for the app itself.
